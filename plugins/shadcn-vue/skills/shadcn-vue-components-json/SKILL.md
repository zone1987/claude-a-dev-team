# shadcn-vue: components.json

Die `components.json`-Datei steuert, wie der shadcn-vue-CLI Komponenten fuer dein
Projekt generiert und platziert. Sie wird mit `npx shadcn-vue@latest init` erzeugt
und ist **nur beim Einsatz des CLI erforderlich** (bei Copy-Paste nicht noetig).

## Reference Files

- `references/components-json.md` — Alle Felder mit Erklaerung und Beispielen:
  $schema, style, typescript, tailwind.config, tailwind.css, tailwind.baseColor,
  tailwind.cssVariables, tailwind.prefix, aliases.utils, aliases.components,
  aliases.ui, aliases.lib, aliases.composables sowie vollstaendiges Beispiel
  aus der manuellen Installation
