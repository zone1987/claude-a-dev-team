# shadcn-vue Textarea Component

Native HTML `<textarea>` wrapped with Tailwind styling and Vue's `useVModel`.
Supports `v-model`, `disabled`, `aria-invalid` validation state, and
`field-sizing-content` for auto-growing height. Compose with `Field`,
`FieldLabel`, and `FieldDescription` for accessible forms.
