# shadcn-vue Table Component

Responsive HTML table built from semantic sub-components. No dependency on
reka-ui — pure HTML wrappers with Tailwind styling. Compatible with
TanStack Table (a `valueUpdater` utility is included). Supports captions,
header, body, footer, and empty states.
