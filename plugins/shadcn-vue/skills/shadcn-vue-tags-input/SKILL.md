# shadcn-vue Tags Input Component

Multi-value tag input built on reka-ui `TagsInputRoot`. Vue-specific component
(reka-ui TagsInput). Tags are rendered as removable chips. Controlled via
`v-model` with a `string[]`. Supports validation state via `aria-invalid`.
