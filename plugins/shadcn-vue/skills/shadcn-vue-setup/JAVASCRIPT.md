# shadcn-vue: JavaScript

shadcn-vue ist in TypeScript geschrieben, stellt aber auch JavaScript-Versionen
der Komponenten bereit. Das Opt-out erfolgt ueber das `typescript`-Flag in
`components.json`.

## Reference Files

- `JAVASCRIPT-DETAIL.md` — typescript: false in components.json (vollstaendiges
  Beispiel), jsconfig.json fuer @/* Path-Alias, CLI-Verhalten bei JS-Projekten
