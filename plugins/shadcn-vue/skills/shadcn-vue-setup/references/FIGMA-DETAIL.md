# shadcn-vue: Figma Resources

Community-maintained Figma resources for shadcn-vue design work.

**Note:** These files are contributed by the community. For questions or feedback,
contact the respective Figma file maintainers.

## Paid

- **shadcn/ui kit** by [Matt Wierzbicki](https://x.com/matsugfx)
  URL: https://shadcndesign.com
  A premium, always up-to-date UI kit for Figma — shadcn/ui compatible and optimized
  for smooth design-to-dev handoff.
