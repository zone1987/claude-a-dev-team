# shadcn-vue: Overview

shadcn-vue is a Vue/Nuxt port of the original shadcn/ui (React). It is maintained by
[unovue](https://github.com/unovue) and powered by
[Reka UI](https://reka-ui.com) as its headless component primitive layer.

**This is not a component library. It is how you build your component library.**
