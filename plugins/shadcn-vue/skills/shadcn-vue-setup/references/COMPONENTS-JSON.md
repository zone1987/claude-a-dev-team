# shadcn-vue: components.json

The `components.json` file controls how the shadcn-vue CLI generates and places
components for your project. It is created by `npx shadcn-vue@latest init`
and is **only required when using the CLI** (not needed for copy-paste).

## Reference Files

- `COMPONENTS-JSON-DETAIL.md` — All fields with explanations and examples:
  $schema, style, typescript, tailwind.config, tailwind.css, tailwind.baseColor,
  tailwind.cssVariables, tailwind.prefix, aliases.utils, aliases.components,
  aliases.ui, aliases.lib, aliases.composables plus a complete example
  from the manual installation
