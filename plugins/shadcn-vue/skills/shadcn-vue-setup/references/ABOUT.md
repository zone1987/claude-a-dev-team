# shadcn-vue: About

## About

[shadcn-vue](https://shadcn-vue.com) is a port of [shadcn/ui](https://ui.shadcn.com)
for Vue/Nuxt. It is maintained by [unovue](https://github.com/unovue).

## Key Distinction: shadcn-vue vs. shadcn/ui

- **shadcn/ui** is the original React-based project by @shadcn.
- **shadcn-vue** is the Vue/Nuxt port, maintained by unovue.
- The headless primitive layer differs:
  - shadcn/ui uses **Radix UI** (React)
  - shadcn-vue uses **Reka UI** (Vue) — formerly known as Radix Vue

## Reka UI

[Reka UI](https://reka-ui.com) is the headless component layer powering shadcn-vue.
It is the successor to Radix Vue. As of shadcn-vue@latest, Reka UI v2 is used.

For projects that want to keep using Radix Vue, a separate registry is available:
https://radix.shadcn-vue.com (run `shadcn-vue@radix` instead of `shadcn-vue@latest`).
