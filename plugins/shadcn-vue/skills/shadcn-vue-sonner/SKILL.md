# shadcn-vue Sonner Component

Opinionated toast component for Vue based on `vue-sonner`. The `<Toaster />`
wrapper applies shadcn-vue theming (CSS variables) and injects lucide icons
for the built-in toast types. The `toast()` function from `vue-sonner` is
used directly to trigger notifications.

Note: The older `toast` component from shadcn-vue v3 is **deprecated**.
Use `sonner` instead. See https://v3.shadcn-vue.com/docs/components/toast
for the old docs if needed.
