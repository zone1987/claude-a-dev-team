# shadcn-vue Typography

## Overview

shadcn-vue ships NO typography component files. Typography is a set of Tailwind CSS utility class conventions applied directly on semantic HTML elements. This page documents all class combinations as used in the shadcn-vue documentation and examples.

## Usage pattern

Apply classes directly to HTML elements:

```vue
<h1 class="scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl">
  Heading 1
</h1>
```
