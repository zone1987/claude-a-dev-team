# Kbd — Installation

## CLI (recommended)

```bash
npx shadcn-vue@latest add kbd
```

## Manual

1. No external dependencies (no reka-ui primitives needed)

2. Copy the following files to `src/components/ui/kbd/`:
   - `Kbd.vue`
   - `KbdGroup.vue`
   - `index.ts`

## Imports

```ts
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```
