# shadcn-vue: Typography

shadcn-vue provides ready-made typography style classes that can be applied
directly as Tailwind classes on HTML elements.

## Available types

| Class / Selector | Usage |
|---|---|
| h1 | Largest heading (scroll-m-20 text-4xl font-extrabold) |
| h2 | Second level (scroll-m-20 border-b pb-2 text-3xl font-semibold) |
| h3 | Third level (scroll-m-20 text-2xl font-semibold) |
| h4 | Fourth level (scroll-m-20 text-xl font-semibold) |
| p | Paragraph (leading-7, margin-top on a following paragraph) |
| blockquote | Quotation (mt-6 border-l-2 pl-6 italic) |
| table | Table structure (w-full caption-bottom text-sm) |
| list | Bullet list (my-6 ml-6 list-disc) |
| Inline code | Code in running text (relative rounded bg-muted px-[0.3rem] font-mono text-sm) |
| Lead | Highlighted intro text (text-xl text-muted-foreground) |
| Large | Larger text (text-lg font-semibold) |
| Small | Small text (text-sm font-medium leading-none) |
| Muted | Subdued text (text-sm text-muted-foreground) |
