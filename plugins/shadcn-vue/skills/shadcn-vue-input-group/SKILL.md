# shadcn-vue InputGroup

Wrapper-Komponente, die Input- oder Textarea-Felder mit Addons (Icons, Texte, Buttons) kombiniert. Unterstuetzt alle vier Ausrichtungen: inline-start, inline-end, block-start, block-end.
