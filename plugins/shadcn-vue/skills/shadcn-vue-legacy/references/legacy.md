# shadcn-vue: Legacy Docs

The current shadcn-vue documentation covers shadcn-vue with Tailwind v4.

For projects using **shadcn-vue with Tailwind v3** (and the older Radix Vue primitive
layer instead of Reka UI), the legacy documentation is available at:

**https://v3.shadcn-vue.com**

## When to use the legacy docs

- Your project uses Tailwind CSS v3
- Your project uses `radix-vue` (not `reka-ui`)
- You are running `shadcn-vue@radix` instead of `shadcn-vue@latest`

## Migration

To migrate from v3 to the current version with Tailwind v4:
See the Tailwind v4 upgrade guide in the `shadcn-vue-tailwind-v4` skill.

Source: `/tmp/shadcn-vue-repo/apps/v4/content/docs/11.legacy.md`
