# shadcn-vue Stepper Component

Multi-step progress indicator built on reka-ui's `StepperRoot`. Vue-specific
component (reka-ui Stepper). Supports horizontal and vertical orientation,
controlled step via `v-model`, disabled steps, and full icon/text customization.
