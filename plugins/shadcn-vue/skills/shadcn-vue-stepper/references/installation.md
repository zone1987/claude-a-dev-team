# Installation

## CLI (empfohlen)

```bash
npx shadcn-vue@latest add stepper
```

## Manuell

### Dependencies

```bash
npm install reka-ui
```

Copy source files from GitHub into `src/components/ui/stepper/`:
https://github.com/unovue/shadcn-vue/tree/dev/apps/v4/registry/new-york-v4/ui/stepper

Update import paths to match your project (e.g. `@/lib/utils`).
