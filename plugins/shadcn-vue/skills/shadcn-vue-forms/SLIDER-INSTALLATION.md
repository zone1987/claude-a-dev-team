# Installation

## CLI (empfohlen)

```bash
npx shadcn-vue@latest add slider
```

## Manuell

### Dependencies

```bash
npm install reka-ui
```

Copy the source files from GitHub into `src/components/ui/slider/`:
https://github.com/unovue/shadcn-vue/tree/dev/apps/v4/registry/new-york-v4/ui/slider

Update import paths to match your project (e.g. `@/lib/utils`).
