# Label — Installation

## CLI (recommended)

```bash
npx shadcn-vue@latest add label
```

## Manual

1. Install dependencies:

```bash
npm install reka-ui @vueuse/core
```

2. Copy the following files to `src/components/ui/label/`:
   - `Label.vue`
   - `index.ts`

## Imports

```ts
import { Label } from "@/components/ui/label"
```
