# Installation

## CLI (recommended)

```bash
npx shadcn-vue@latest add switch
```

## Manual

### Dependencies

```bash
npm install reka-ui
```

Copy the source from GitHub into `src/components/ui/switch/`:
https://github.com/unovue/shadcn-vue/tree/dev/apps/v4/registry/new-york-v4/ui/switch

Update import paths to match your project (e.g. `@/lib/utils`).
