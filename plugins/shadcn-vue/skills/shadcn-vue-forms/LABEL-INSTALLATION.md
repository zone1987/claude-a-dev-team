# Label — Installation

## CLI (empfohlen)

```bash
npx shadcn-vue@latest add label
```

## Manuell

1. Abhangigkeiten installieren:

```bash
npm install reka-ui @vueuse/core
```

2. Folgende Dateien nach `src/components/ui/label/` kopieren:
   - `Label.vue`
   - `index.ts`

## Imports

```ts
import { Label } from "@/components/ui/label"
```
