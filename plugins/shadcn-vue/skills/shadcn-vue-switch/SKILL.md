# shadcn-vue Switch Component

Toggle switch built on reka-ui `SwitchRoot` and `SwitchThumb`. Supports
controlled and uncontrolled usage, disabled state, custom thumb content via
the `#thumb` slot, and two sizes via the `size` prop.
