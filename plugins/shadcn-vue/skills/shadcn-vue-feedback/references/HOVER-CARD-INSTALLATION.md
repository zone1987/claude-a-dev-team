# HoverCard — Installation

## CLI

```bash
npx shadcn-vue@latest add hover-card
```

## Manual

### Dependencies

```bash
npm install reka-ui
```

### Steps

1. Copy the source code into `components/ui/hover-card/`
2. Adjust the import paths

### Import

```vue
<script setup lang="ts">
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from '@/components/ui/hover-card'
</script>
```
