# Collapsible — Installation

## CLI (recommended)

```bash
npx shadcn-vue@latest add collapsible
```

This adds the following files to your project:
- `src/components/ui/collapsible/Collapsible.vue`
- `src/components/ui/collapsible/CollapsibleContent.vue`
- `src/components/ui/collapsible/CollapsibleTrigger.vue`
- `src/components/ui/collapsible/index.ts`

## Manual

1. Install the reka-ui peer dependency:

```bash
npm install reka-ui
```

2. Copy the source files (see [source.md](COLLAPSIBLE-SOURCE.md)) into your project, e.g. `src/components/ui/collapsible/`.

3. Update import paths as needed to match your project structure.
