# shadcn-vue OTP Blocks: otp-04, otp-05

## Block: otp-04

**Description:** OTP-Formular im zweispaltigen Card-Layout mit Bild-Panel und ToS-Hinweis.

**Installation:**
```bash
npx shadcn-vue@latest add otp-04
```

**Files:**
- `page.vue`
- `components/OTPForm.vue`

### page.vue
```vue
<script setup lang="ts">
import OTPForm from "@/registry/new-york-v4/blocks/otp-04/components/OTPForm.vue"
</script>

<template>
  <div class="flex min-h-svh w-full items-center justify-center p-6 md:p-10">
    <div class="w-full max-w-sm md:max-w-3xl">
      <OTPForm />
    </div>
  </div>
</template>
```

**Installation:**
```bash
npx shadcn-vue@latest add otp-05
```

- `page.vue`
- `components/OTPForm.vue`
