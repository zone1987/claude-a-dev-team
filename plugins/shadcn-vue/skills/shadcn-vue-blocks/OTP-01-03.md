## Block: otp-01

**Description:** Einfaches OTP-Verifizierungsformular zentriert in einer Card.

**Installation:**
```bash
npx shadcn-vue@latest add otp-01
```

**Files:**
- `page.vue`
- `components/OTPForm.vue`

### page.vue
```vue
<script setup lang="ts">
import OTPForm from "@/registry/new-york-v4/blocks/otp-01/components/OTPForm.vue"
</script>

<template>
  <div class="flex min-h-svh w-full items-center justify-center p-6 md:p-10">
    <div class="w-full max-w-xs">
      <OTPForm />
    </div>
  </div>
</template>
```
