# shadcn-vue Tabs Component

Layered content panels built on reka-ui `TabsRoot`. Supports two visual
variants (default pill-style and line underline), horizontal and vertical
orientations, icons in triggers, disabled tabs, and both controlled and
uncontrolled usage.
