## `addCustomRegexp`

**Purpose:** Triggered when an unknown validation option (`rgxp`) is found. Allows your own validation rules for form fields and DCA fields.

**Parameters:**

| # | Type | Name | Description |
|---|-----|------|-------------|
| 1 | `string` | `$regexp` | The unknown regular expression identifier |
| 2 | `mixed` | `$input` | The input value to validate |
| 3 | `\Contao\Widget` | `$widget` | The form widget |

**Returns:** `bool` – `true` = stop processing (do not pass on to further hooks), `false` = keep processing.

**Timing:** During form field validation, when an unknown `rgxp` value is found in DCA fields or form generator text fields.

```php
use Contao\CoreBundle\DependencyInjection\Attribute\AsHook;
use Contao\Widget;

#[AsHook('addCustomRegexp')]
class AddCustomRegexpListener
{
    public function __invoke(string $regexp, $input, Widget $widget): bool
    {
        if ('plz' !== $regexp) {
            return false; // not responsible
        }
        // Validate a German postal code (5 digits)
        if (!preg_match('/^\d{5}$/', $input)) {
            $widget->addError('Please enter a valid postal code.');
        }
        return true; // own processing finished
    }
}
```

Usage in the DCA:
```php
'fields' => [
    'plz' => [
        'inputType' => 'text',
        'eval' => ['rgxp' => 'plz'],
    ]
]
```

## `colorizeLogEntries`

**Purpose:** Triggered when a log entry is displayed in the back end. Allows adjusting its presentation (label/CSS).

**Parameters:**

| # | Type | Name | Description |
|---|-----|------|-------------|
| 1 | `array` | `$row` | The log entry record |
| 2 | `string` | `$label` | Label generated by Contao |

**Returns:** `string` – The modified label.

**Timing:** While log entries are displayed in the back end.

```php
#[AsHook('colorizeLogEntries')]
class ColorizeLogEntriesListener
{
    public function __invoke(array $row, string $label): string
    {
        if ('ERROR' === $row['action']) {
            $label = preg_replace(
                '@^(.*</span> )(.*)$@U',
                '$1<span class="tl_red">$2</span>',
                $label
            );
        }
        return $label;
    }
}
```

## `initializeSystem`

**Purpose:** Triggered immediately after the system initialization has finished and **before** the request processing starts. No Contao request scope is set, and no language redirect has been performed.

**Parameters:** none

**Returns:** `void`

**Timing:** After the system initialization, before the request processing.

```php
#[AsHook('initializeSystem')]
class InitializeSystemListener
{
    public function __invoke(): void
    {
        // Very early initialization logic
        // No Contao request scope available!
    }
}
```

## `loadLanguageFile`

**Purpose:** Triggered when a language file is loaded through `\Contao\System::loadLanguageFile()`.

**Parameters:**

| # | Type | Name | Description |
|---|-----|------|-------------|
| 1 | `string` | `$name` | Language file name without the extension (e.g. `tl_content`) |
| 2 | `string` | `$currentLanguage` | The loaded language (e.g. `de`) |
| 3 | `string` | `$cacheKey` | Internal cache key of the loaded file |

**Returns:** `void`

**Timing:** When the system loads a language file.

```php
#[AsHook('loadLanguageFile')]
class LoadLanguageFileListener
{
    public function __invoke(string $name, string $currentLanguage, string $cacheKey): void
    {
        if ('tl_content' === $name && 'de' === $currentLanguage) {
            // Add your own translations
            $GLOBALS['TL_LANG']['tl_content']['myField'] = ['Mein Feld', 'Beschreibung'];
        }
    }
}
```

## `parseDate`

**Purpose:** Triggered whenever `\Contao\Date::parse()` is used. Allows custom date formatting based on locale and format.

**Parameters:**

| # | Type | Name | Description |
|---|-----|------|-------------|
| 1 | `string` | `$formattedDate` | The already formatted date |
| 2 | `string` | `$format` | The requested date format |
| 3 | `int\|null` | `$timestamp` | The given timestamp |

**Returns:** `string` – The (possibly modified) formatted date.

**Timing:** When `\Contao\Date::parse()` is called.

```php
#[AsHook('parseDate')]
class ParseDateListener
{
    public function __invoke(string $formattedDate, string $format, int|null $timestamp): string
    {
        // Insert Austrian month names
        return str_replace(
            ['Januar', 'Februar'],
            ['Jänner', 'Feber'],
            $formattedDate
        );
    }
}
```

## `setCookie`

**Purpose:** Triggered when a cookie is sent to the browser. Allows modifying the cookie properties.

**Parameters:**

| # | Type | Name | Description |
|---|-----|------|-------------|
| 1 | `\stdClass` | `$cookie` | Object with the cookie properties (`strName`, `varValue`, `intExpires`, `strPath`, `strDomain`, `blnSecure`, `blnHttpOnly`) |

**Returns:** `\stdClass` – The (possibly modified) cookie object.

**Timing:** When the application sends a cookie to the browser.

> **Deprecated:** Will be removed in Contao 6. Implement a `kernel.response` listener instead.

```php
#[AsHook('setCookie')]
class SetCookieListener
{
    public function __invoke(\stdClass $cookie): \stdClass
    {
        // Set the cookie path to the root
        $cookie->strPath = '/';
        return $cookie;
    }
}
```

## `sqlCompileCommands`

**Purpose:** Triggered while the database update commands are compiled. Allows modifying the SQL statements before they run.

**Parameters:**

| # | Type | Name | Description |
|---|-----|------|-------------|
| 1 | `array` | `$sql` | Array of the changes that will be applied to the database |

**Returns:** `array` – The modified array of database changes.

**Timing:** During the compilation of the database update commands.

```php
#[AsHook('sqlCompileCommands')]
class SqlCompileCommandsListener
{
    public function __invoke(array $sql): array
    {
        // Modify or add SQL statements
        return $sql;
    }
}
```
