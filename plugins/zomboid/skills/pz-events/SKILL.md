# Project Zomboid Lua events

An event is the safe way to react to the game: nothing is overridden, so nothing conflicts with
another mod. Register a handler, and the engine calls it.

```lua
local function onPlayerUpdate(player)
    -- runs every tick, per player
end
Events.OnPlayerUpdate.Add(onPlayerUpdate)
Events.OnPlayerUpdate.Remove(onPlayerUpdate)   -- the same reference, or nothing is removed
```

`Remove` compares by identity. An anonymous function passed to `Add` can never be removed, so keep a
named local for anything you might detach.

## What to know before hooking

- **`OnTick` and `OnPlayerUpdate` run every frame.** Work belongs on a coarser event
  (`EveryOneMinute`, `EveryTenMinutes`, `EveryHours`, `EveryDays`) or behind your own timer. A loop
  over containers in `OnTick` is the usual cause of a mod that "makes the server lag".
- **Guard every argument.** A handler that errors on nil takes the rest of that event's dispatch with
  it in the common case, so other mods' handlers stop running too. Check before you dereference.
- **The side matters.** An event referenced only from `client/` does not fire on a dedicated server.
  The catalogue records which directories reference each event.
- **Many things have no event.** That is the single biggest surprise, and it has a section below.

## When no event exists

Several things a mod wants to hook simply have none. The helicopter is the clearest case: there is no
`OnHelicopter*` event. It is driven by `zombie.iso.Helicopter`, triggered by
`zombie.commands.serverCommands.ChopperCommand` and carried by
`zombie.network.packets.actions.HelicopterPacket` — all Java, none of it emitting to Lua.

The pattern for that situation:

1. **Find the Java object that holds the state** — `pz-java-api` carries all 3,965 classes.
2. **Poll it on a coarse timer**, not on `OnTick`. Once a second is usually far more than enough.
3. **Compare against the previous value** and emit your own event on a change, so the rest of your
   mod stays event-driven:
   ```lua
   local last = nil
   Events.EveryOneMinute.Add(function()
       local now = <read the Java state>
       if now ~= last then
           last = now
           triggerEvent("MyModHelicopterChanged", now)
       end
   end)
   ```
4. **Register your event name once** with `LuaEventManager.AddEvent("MyModHelicopterChanged")` so
   `Events.MyModHelicopterChanged.Add` works for other code.

That is also how a mod exposes its own hooks to other mods, and how a bridge to an external tool gets
a single place to write from.
