# Project Zomboid crafting

Build 42 replaced the old `recipe` block with **`craftRecipe`**, and added an **entity/component**
system for crafting stations. A build 41 recipe does not load in build 42, so anything written
against the old syntax needs rewriting rather than porting.

A `craftRecipe` names its inputs, its outputs, a time, and optionally a skill requirement and a
crafting station. Inputs use a dense syntax worth reading carefully:

```
item 1 [Base.WoodenStick2;Base.TreeBranch2;Base.Handle] mode:keep flags[Prop1],
```

That is: one of an alternatives list, kept rather than consumed, held in a particular hand slot. The
tokens are positional and easy to get wrong — take them from a real recipe in the data table rather
than composing them from memory.

## Adding a recipe from a mod

- The script goes in your mod's `media/scripts/`, in a `module` block. It does not replace the base
  game's recipes unless it reuses a recipe name.
- Both client and server load scripts, so a recipe needs no sync.
- Gating on a skill or a recipe book is done in the script, not in Lua.
- Lua hooks — `OnCreate` and similar keys — run when the recipe completes, and run **server-side**
  in multiplayer. Anything a hook changes in the world belongs there rather than in a client file.
