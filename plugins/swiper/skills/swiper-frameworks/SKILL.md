# Swiper framework bindings

Each binding wraps the same core; what differs is how slides are declared and how the instance is reached.

## Reference map

- **[ANGULAR.md](references/ANGULAR.md)**: As of Swiper v9: no separate Angular components anymore.
- **[REACT.md](references/REACT.md)**: `import { Swiper, SwiperSlide } from 'swiper/react'` — fully typed, React 18-compatible.
- **[SOLID.md](references/SOLID.md)**: As of Swiper v9: no separate SolidJS components.
- **[SVELTE.md](references/SVELTE.md)**: As of Swiper v9: no separate Svelte components.
- **[VUE.md](references/VUE.md)**: `import { Swiper, SwiperSlide } from 'swiper/vue'` — Composition API, Vue 3, all parameters as props.
