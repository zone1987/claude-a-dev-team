# Shopware 6 – Product Bundles (Blueprint / Insider Preview)

Bundle several products into one bundle offer and sell it as a standalone product
with an optional discount. **Blueprint status** – minimum plan: **Evolve**, from version **6.7.9.0**.

## Quick start

1. **Kataloge** (Catalogues) **> Bundles** → create a bundle
2. Name, product number, description → media → add **at least 2 products**
3. Configure the discount (percentage or fixed amount) → set **Sichtbarkeit** (Visibility) and **Verkaufskanal** (Sales channel)

Full reference: `PREVIEWS-BUNDLES-BUNDLES.md`
