# Shopware 6 – Create an order manually in the admin

Guide to creating manual orders via the Shopware administration.

Detailed documentation: [CREATE-DETAIL.md](CREATE-DETAIL.md)

## Quick overview

1. Bestellungen (Orders) > "Bestellung anlegen" (Create order)
2. Select a customer or create a new one
3. Add products / empty line items / credit notes
4. Configure options (payment, shipping, addresses, currency)
5. "Bestellung speichern" (Save order) → the confirmation e-mail is sent automatically
