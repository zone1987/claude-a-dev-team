# sw-merchant-marketing-rule-builder

This skill documents the Rule Builder in Shopware 6 (**Einstellungen > Automatisierung > Rule Builder** — Settings > Automation > Rule Builder). It contains all condition categories (**Allgemein** – General, **Bestellungen** – Orders, **Kunde** – Customer, **Marketing**, **Positionen im Warenkorb** – Line items in the cart, **Warenkorb** – Cart), all 11 operator types, the rule structure with AND/OR combinations, the preview mode as well as the import/export function for rules. Particularly relevant for creating conditions in discount promotions.
