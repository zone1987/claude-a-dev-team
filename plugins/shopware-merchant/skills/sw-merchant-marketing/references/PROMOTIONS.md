# sw-merchant-marketing-promotions

This skill covers the complete configuration of the discount and promotion modules in Shopware 6. It contains all setting options (general settings, promotion codes, conditions, discounts), explains the four rule types for conditions, the three discount types as well as the set group configurations. In addition, 15 practical application examples are documented (free shipping, buy-3-pay-2, bundles, customer group discounts and so on).

For promotion codes (fixed and individual codes) see additionally `sw-merchant-marketing-codes`. For the Rule Builder used to create conditions see `sw-merchant-marketing-rule-builder`.
