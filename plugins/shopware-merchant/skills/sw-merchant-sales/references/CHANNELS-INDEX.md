# Shopware 6 – Verkaufskanäle (Sales channels): index

> Source: https://docs.shopware.com/de/shopware-6-de/einstellungen/Verkaufskanaele

---

## Included skills

| Skill | Topic |
|---|---|
| `sw-merchant-sales-channels` | Overview, types, favourites, customer binding |
| `sw-merchant-sales-channels-create` | Create a channel, choose type |
| `sw-merchant-sales-channels-config` | Basic settings, navigation, payment, analytics |
| `sw-merchant-sales-channels-domains` | Domains, languages, currencies, hreflang |
| `sw-merchant-sales-channels-products` | Product assignment via the channel tab |
| `sw-merchant-sales-channels-api-access` | Generate and use API keys |
| `sw-merchant-sales-channels-social-shopping` | Facebook, Instagram, Google Shopping, Pinterest |
| `sw-merchant-sales-channels-product-comparison` | XML/CSV feeds, Twig templates, variables |
| `sw-merchant-sales-channels-agentic` | JSONL feed for AI platforms (as of 6.7.10) |
