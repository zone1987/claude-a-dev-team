# Shopware 6 – Agentic Commerce Product Feed

JSONL product feed for AI platforms (as of Shopware 6.7.10.0).

## Function

- Central platform for AI-driven product distribution
- Standard-compliant JSONL feed
- Pre-configured OpenAI template
- Tracking via affiliate and campaign code
- Statistics: orders, customers, revenue

## Configuration

1. Create the channel (type: Agentic Commerce)
2. Choose the OpenAI template
3. Enter the return policy URL
4. Assign variant attributes (colour, size, gender, material)
5. Set the affiliate and campaign code for tracking
6. Assign a Dynamische Produktgruppe (Dynamic product group)
7. Choose the generation interval (including live mode)

## Note

ChatGPT marketplace registration is currently available **only in the USA**.
