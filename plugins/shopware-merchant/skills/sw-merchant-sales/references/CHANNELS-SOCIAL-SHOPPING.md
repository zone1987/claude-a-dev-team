# Shopware 6 – Social Shopping

Product feeds for social media platforms (from Shopware Rise onwards).

## Supported platforms

| Platform | Feed type | Particularity |
|---|---|---|
| **Facebook** | XML | Referral code for tracking |
| **Instagram** | XML | Identical to Facebook |
| **Google Shopping** | XML | Domain verification required |
| **Pinterest** | No feed | Meta data / rich pins |

## Basic principle

1. Create a Social Shopping channel (choose the type)
2. Assign the storefront channel + domain
3. Dynamische Produktgruppe (Dynamic product group) for product selection
4. Enter the export URL in the platform
5. Adjust the template (optional, Twig)

## Prerequisite

Shopware Rise (or higher) plan; activate the extension under Erweiterungen (Extensions) > Meine Erweiterungen (My extensions).
