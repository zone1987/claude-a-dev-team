# Shopware 6 – Domains, languages, currencies

Several domains, each with its own language and currency, can be entered per Verkaufskanal (Sales channel).

## Quick overview

- **Button:** "Allgemein" (General) tab > "Domains" section > "Domain hinzufügen" (Add domain)
- **Mandatory fields:** URL, language, currency, Textbaustein-Set (snippet set)
- **Recommendation:** Enter only `https://` or `http://` (no `www.`) (duplicate content)
- **Cloud:** Create the domain first under Einstellungen (Settings) > System > Domains

## Configuration fields

| Field | Description |
|---|---|
| URL | Domain including protocol (https/http + subdomain) |
| Sprache (Language) | From the languages assigned to the channel |
| Währung (Currency) | From Einstellungen > Regional > Währungen (Currencies) |
| Textbaustein-Set | From Einstellungen > Regional > Textbausteine (Snippets) |
| Hreflang localisation | ISO standard or browser language (ISO recommended) |
