# The decisions behind this standard

The decisions behind this standard live in one place: the plugin rule book in the skill
`sw-guidelines` of the plugin `shopware-quality`.

- Index: `PLUGIN-RULES.md`, the testing decisions are in the chapter `PLUGIN-RULES-TESTING.md`.
- Repository and process decisions (git workflow, built assets, assets build) are in `PLUGIN-RULES-PROCESS.md`.
- Load the skill `sw-guidelines` to read them. The plugins install separately, so this file links to nothing.
