## Deployment-Optionen

| Option | Vorteile |
|--------|---------|
| **AWS Amplify** | Git-Push-Deployment, managed |
| **Cloudflare Pages** | Edge-Deployment, GitHub Actions |
| **Ubuntu Server + PM2** | Self-hosted, volle Kontrolle |
