# Gotenberg PDF manipulation

Operations on a PDF you already have. All live under the PDF engines route and compose in one request.

## Reference map

- **[ATTACHMENTS.md](references/ATTACHMENTS.md)**: Embeds external files as attachments in the PDF container. [ATTACHMENTS-DETAIL](references/ATTACHMENTS-DETAIL.md).
- **[BOOKMARKS.md](references/BOOKMARKS.md)**: Extracts the document outline as JSON or writes new bookmarks into PDFs. [BOOKMARKS-DETAIL](references/BOOKMARKS-DETAIL.md).
- **[CONVERT.md](references/CONVERT.md)**: Converts PDFs into long-term archival formats or accessible PDFs. [CONVERT-DETAIL](references/CONVERT-DETAIL.md).
- **[ENCRYPT.md](references/ENCRYPT.md)**: Protects PDFs with a user/owner password and permission restrictions. [ENCRYPT-DETAIL](references/ENCRYPT-DETAIL.md).
- **[FACTURX.md](references/FACTURX.md)**: Creates standards-compliant Factur-X / ZUGFeRD e-invoices: embeds CII XML as `factur-x.xml`, injects XMP m…. [FACTURX-DETAIL](references/FACTURX-DETAIL.md).
- **[FLATTEN.md](references/FLATTEN.md)**: Converts interactive form fields into static page content. [FLATTEN-DETAIL](references/FLATTEN-DETAIL.md).
- **[MERGE.md](references/MERGE.md)**: Combines several PDF files into a single document. [MERGE-DETAIL](references/MERGE-DETAIL.md).
- **[METADATA.md](references/METADATA.md)**: Reads XMP/Exif metadata via ExifTool and writes new XMP tags. [METADATA-DETAIL](references/METADATA-DETAIL.md).
- **[ROTATE.md](references/ROTATE.md)**: Rotates all or selected pages of a PDF by 90, 180 or 270 degrees. [ROTATE-DETAIL](references/ROTATE-DETAIL.md).
- **[SPLIT.md](references/SPLIT.md)**: Splits PDFs by page intervals or page ranges. [SPLIT-DETAIL](references/SPLIT-DETAIL.md).
- **[STAMP.md](references/STAMP.md)**: Adds a text, image or PDF stamp ON TOP OF the page content. [STAMP-DETAIL](references/STAMP-DETAIL.md).
- **[WATERMARK.md](references/WATERMARK.md)**: Adds a text, image or PDF watermark BEHIND the page content. [WATERMARK-DETAIL](references/WATERMARK-DETAIL.md).
