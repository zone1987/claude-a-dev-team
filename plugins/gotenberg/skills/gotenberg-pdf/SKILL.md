# Gotenberg PDF manipulation

Operations on a PDF you already have. All live under the PDF engines route and compose in one request.

## Reference map

- **[ATTACHMENTS.md](references/ATTACHMENTS.md)**: Embeds external files as attachments in the PDF container.
- **[BOOKMARKS.md](references/BOOKMARKS.md)**: Extracts the document outline as JSON or writes new bookmarks into PDFs.
- **[CONVERT.md](references/CONVERT.md)**: Converts PDFs into long-term archival formats or accessible PDFs.
- **[ENCRYPT.md](references/ENCRYPT.md)**: Protects PDFs with a user/owner password and permission restrictions.
- **[FACTURX.md](references/FACTURX.md)**: Creates standards-compliant Factur-X / ZUGFeRD e-invoices: embeds CII XML as `factur-x.xml`, injects XMP m….
- **[FLATTEN.md](references/FLATTEN.md)**: Converts interactive form fields into static page content.
- **[MERGE.md](references/MERGE.md)**: Combines several PDF files into a single document.
- **[METADATA.md](references/METADATA.md)**: Reads XMP/Exif metadata via ExifTool and writes new XMP tags.
- **[ROTATE.md](references/ROTATE.md)**: Rotates all or selected pages of a PDF by 90, 180 or 270 degrees.
- **[SPLIT.md](references/SPLIT.md)**: Splits PDFs by page intervals or page ranges.
- **[STAMP.md](references/STAMP.md)**: Adds a text, image or PDF stamp ON TOP OF the page content.
- **[WATERMARK.md](references/WATERMARK.md)**: Adds a text, image or PDF watermark BEHIND the page content.
