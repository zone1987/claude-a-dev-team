# Prerequisites

What must be in place before adding ReUI to a project.

## Framework requirements

ReUI is built on the latest **React 19** and **Tailwind CSS v4**. The project must be set up
with these technologies before proceeding.

Upstream recommends following:
- the official shadcn/ui Installation Guide
- the `shadcn create` setup

to prepare the environment before installing ReUI items.

## CLI installation prerequisites (License Setup page)

For premium (paid) registry installs specifically, the License Setup page states these
prerequisites:

- A React project with shadcn/ui initialized
- Node.js 18 or newer
- A `components.json` file in the project root

## What ReUI is

A first-class shadcn registry of open source components and blocks, compatible with Base UI,
Radix UI, and Tailwind CSS. The same catalog developers browse and install is also served to AI
agents through the MCP server and Agent Skills.

### Catalog shape (from the Introduction page)

- **Components** - 21 free ReUI primitives (data-grid, event-calendar, gantt, cascader, kanban,
  filters, date-selector, stepper, icon-tile, tree, and others): parts you compose yourself.
- **Examples** - 1,000+ free open source component examples, each primitive configured for a
  real use case.
- **Blocks** - 485+ Pro blocks across five groups: Application, Data Grid, Solutions, eCommerce,
  and Marketing. Complete sections you drop into a page. **Paid.**
- **Templates** - multi-page templates assembled entirely from blocks. **Paid.**
- **Icons** - 562 icons in four styles (outline, solid, duotone, filled) matching the rest of the
  catalog. **Paid** (part of Ultimate; see PLANS.md).

Components and examples are free; blocks, icons, and templates belong to the paid plans.

### Foundation

Every component, example, and block ships in **two versions**: one built on Base UI, one on
Radix UI — so ReUI fits both new projects and existing codebases. Everything is styled with
Tailwind CSS v4 and available in multiple styles.
